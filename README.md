# NEV MOTO KLİNİK

Nevşehir motosiklet ve ATV servisi için Türkçe tanıtım sitesi. Randevu [Instagram](https://www.instagram.com/nevmoto_klinik50/) mesajıyla alınır.

Canlı adres: https://hbuminy.github.io/nevmoto/

İletişim bilgileri işletmenin yayımladığı siteden ve Instagram hesabından alınmıştır.

## Geliştirme

```bash
npm install
npm run dev
```

## Derleme

```bash
npm run build
```

GitHub Actions üzerinde `GITHUB_ACTIONS` tanımlıyken Vite `base` değeri `/nevmoto/` olur. Yerelde kök dizin kullanılır.

## Yayım

`main` dalına yapılan her itme `.github/workflows/pages.yml` ile GitHub Pages'e gider.
